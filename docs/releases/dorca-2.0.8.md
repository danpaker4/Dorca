## Faster TypeScript navigation

- Go to Definition and Find All References now use Microsoft's native TypeScript language server for configured JavaScript and TypeScript projects.
- Project state stays warm across searches, with background preparation when a TypeScript editor opens.
- Renamed imports, reexports, unsaved files, and retained drafts participate in semantic navigation without unrelated text matches.
- Older remote hosts and unconfigured reference searches retain the existing worker fallback.

This release includes the Windows x64 installer and automatic-update metadata.
