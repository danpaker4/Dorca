Dorca 2.0.14 improves Git blame and diff navigation.

- Use **Open Changes** in a blame card to open that file's parent-to-commit diff in a normal editor tab.
- Show blame on both sides of file and combined diffs, using each side's revision, even when blame is disabled for ordinary editors.
- Use Go to Definition on the new side of branch and staged TypeScript/JavaScript diffs.
- Show blame for every selected line, with a larger separator and spacing that scales with the editor font.
- Keep history cards open while hovering, allow wider cards to overlap the sidebar, and show only the selected line's change in the preview.
- Remove the duplicate committer row and the persistent historical-definition notice.

This release includes only the Windows x64 installer and automatic-update metadata.
